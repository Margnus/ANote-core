## 候选与工具链记录

每份新平台回执记录源码/构建输入、构建模式、实际安装摘要、OS build、设备、样本hash、测试入口和未覆盖范围。报告有自己的有效范围；旧报告不能被本表提升为当前候选通过。

Windows 构建使用可执行 Python 路径设置 `PYTHON_BIN`，避免 `python3` 商店占位程序；JDK 与 Kotlin/AGP/Gradle 组合按工程锁定版本使用。首次运行先预检现有工具和设备，不以重复下载/重建代替环境定位。候选依赖图、二进制公开面及最低系统运行均为独立检查项。
