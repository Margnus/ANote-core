# M-2A：共同笔刷覆盖规则与解析oracle

2026-10-15，DEV-027。接续M-3桌面实验，先定义可被两端消费的覆盖语义。代码为internal BrushEnvelopePoc，ruleId为swept-discs-draft-1；未接入App、未公开SDK，也不把候选规则写入现有备份的algorithmVersion承诺。已有MONOLINE/PRESSURE/HIGHLIGHTER数据字段不表示已实现三笔刷生产渲染。

## 候选规则

- MONOLINE：半径width/2，折线连续扫掠圆盘；圆端点、圆连接，单点是圆盘。
- PRESSURE：半径width/2×(0.25+0.75×pressure)，相邻真实样本的中心和半径均线性插值。0压力保持25%最小宽度，这是待体验评审的明确候选，不冒充旧库或平台默认笔感。不加入速度修正、平滑或预测样本；原始真实点全部保留。
- HIGHLIGHTER：同MONOLINE覆盖，原ARGB alpha乘0.25；整笔覆盖先做union，再应用一次source alpha。回折/自交不在同一笔内重复变深，不同对象依规范z序source-over。尚非矩形笔尖、乘色混合或跨笔合并。

解析查询把scene点逆变换回笔迹局部坐标，判断其是否属于连续扫掠圆盘的并集。对每段最小化`|p-(a+t*d)|²-(r+t*dr)²`，t在闭区间[0,1]；凸二次式查驻点，凹/线性式查端点。实际距离按几何形式计算，避免用大二次系数相减。不能只在“最近中心线投影”处插值半径：渐变宽度下该做法会漏掉外侧覆盖；测试有明确反例。

paintedBounds对每个真实样本的变换圆盘计算：世界中心±r×仿射矩阵行向量范数。由于中心和半径均线性，段内极值不会超出两个端点的极值。它覆盖非均匀缩放、斜切和反射，不把变换后的圆仍当原半径圆。此处边界不包含未来光栅抗锯齿/滤波外扩；接入tile/脏区时必须按后端像素过滤半径继续扩张。

## 所有权、限制与失败

输入StrokeSamples本身是不可变防御副本，oracle持有它及独立半径数组；不转存个人笔记，不建立第二个Scene。默认最多200,000真实样本，超过在分配半径数组前返回sample-budget；不抽稀/截断真实点。未知brush版本、不可逆/数值近奇异变换、世界边界溢出均显式Rejected。maxSamples是实验准入，不是最终产品限制。

构建O(N)，每点contains查询最坏O(N)，需保留原样本与N个Double半径。它是正确性参照，**不能逐像素用于生产百万点绘制**。没有三角化、抗锯齿、自交轮廓布尔化、tile栅格、缓存、调度、GPU或实际heap测量。透明度为0时保留几何可查询性，渲染可见性由调用方判断。

## 黄金样本与接缝反例

[brush-golden.json](../fixtures/geometry/brush-golden.json)是手工推导的整数scene格点覆盖，含圆点、压力渐变、荧光笔折返三组固定mask及alpha。JVM测试读取固定文件，逐点核对，不通过即时调用另一份同算法生成“期望”。格点属于二值解析覆盖，边界为闭区间；它不是原生抗锯齿像素黄金图。

七项commonTest覆盖圆端点/急转外角、压力扫掠反例、驻点/包含圆盘、荧光笔一次alpha、仿射椭圆/斜切、版本/预算/奇异/溢出拒绝。另有100条变换压力笔、每条21个内部探针，检查实际覆盖不会被M-3网格或STR树包围盒漏掉；包含反射、斜切与非均匀缩放。此接缝仅在实验测试接入，不改应用渲染路径。
