# 只读遍历支持边界（C1候选）

2026-10-26。对应ENG-04/ENG-19与C1第3/4项。此处审查当前四个绘制消费者，不批准全部导出API、外部raw下标或mutable owner迁移。

| 调用 | 当前支持与责任 | 失败边界 |
|---|---|---|
| Notebook.page/stroke及point系列 | 同一owner先读当前pageCount/strokeCount，再在同一同步调用中取得原页面/StrokeObject；点下标按已取得对象的samples.size限定 | 下标是程序前置条件；当前无NSError，不能从Swift用try接任意越界。Kotlin/JVM与Native的越界异常测试只证明原内容和活动输入未被更改，不证明跨Swift可恢复 |
| Notebook.snapshot/capture/captureRecovery | 仍检查原owner；返回原不可变root/checkpoint，pending必须用完整恢复捕获 | 返回值不转移Notebook线程许可。捕获普通正文不保存未完成笔，也不能替代完整pending责任 |
| 已取得StrokeObject/StrokeSamples | 不可变原引用，标量数组不逃逸；按该对象size读取，在页面切换、undo或Notebook退休后仍保持原值 | 调用者仍承担所持原root/对象/样本的保留责任，不能把退休/取消当物理回收。直接值getter的下标仍有前置条件 |
| 可变Notebook跨owner调用 | 明确不支持；原ownerCheck错误继续传播 | 不能catch后换第二authority、忽略检查或用immutable对象可读推导mutable对象可接管。Swift任意错误owner调用不是typed恢复通道 |
| 页/笔数改变后继续使用旧Notebook下标 | 不支持旧下标身份稳定；必须重新读当前count，或明确持有此前的immutable对象 | 下标不是ObjectId、内容revision或session身份；不能跨异步编辑/页切换把原下标当稳定handle |

## 四个消费者的实际调用

| 消费者 | 当前路径 | 同步边界 |
|---|---|---|
| 原Android InkCanvasView | onDraw按notebook.strokeCount取原stroke，再按samples.size建Path | 主owner绘制，循环内无异步调度或应用回调；渲染交付在循环前选择，当前页缓存另以revision/page校验 |
| 原Apple InkUIView | draw按note.strokeCount取原stroke与samples，再按该samples.size建立UIBezierPath | UIKit主owner绘制；背景和renderModel调用在遍历前完成，循环无await或外部编辑回调；缓存按revision/page校验 |
| Android独立SketchView | 原内存Notebook，重建路径时按当前count/原samples遍历 | 固定单页MONOLINE样例、owner绘制；非生产多文档/异步renderer契约 |
| Apple独立SketchCanvas | draw按当前count取原stroke，private path仅遍历该samples | 注入背景在取得count前调用；遍历中不调用应用注入回调。固定单页，不沿用生产页导航保证 |

这些路径不存在外部raw下标消费者，因此本轮保留可信同步下标契约，不添加每点分配包装、第二内容模型或快照队列。未来增加外部索引协议、异步读取或可重入回调时，必须先规定ID/revision/session核对及typed失败，重新验证；本表不能自动批准新入口。

[来源报告](../reports/read-traversal.json)记录编译头、当前源码和实际测试范围。四消费者的循环检查是来源绑定的静态审查；公共测试验证原Notebook状态及immutable引用，Swift实际测试验证有效遍历和真实owner退休。没有普通系统UI/真触笔、物理heap/延迟、完全owner丢失或跨线程mutable接管结论；原生产存储/C1/M-1门禁保持。
