# NoteCore 0.1.0 预览版

目标：先在手机/平板体验离线手写与本机保存，不是完整P0或正式架构冻结版本。范围/限制见[预览ADR](adr/0005-packaged-preview-vertical-slice.md)。

## Android

独立包名`dev.notecore.preview`，Android8.0/API26及以上；不会覆盖旧JNotes。使用开发调试签名。APK由`dist/NoteCore-0.1.0-preview.apk`提供，SHA与构建信息见[构建报告](../reports/preview-build.json)及dist/SHA256SUMS。dist为本地产物，不提交二进制至Git。

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
bash ci/package-android-preview.sh
adb install -r dist/NoteCore-0.1.0-preview.apk
adb shell am start -n dev.notecore.preview/dev.notecore.app.MainActivity
```

SDK需platform36、build-tools35或以上；初次下载公开构建依赖。包装入口会验证共享测试、assemble、lint及产物/源码指纹；旧APK不能靠修改报告冒充新构建。

新建笔记后可直接书写；点击标题重命名；横向工具栏选颜色与粗细；撤销/重做处理整笔。自动保存只在完成写入后显示“已保存到本机”；失败时先保留当前会话并重试，别直接卸载。手指开关关闭后仅接触笔，默认开启便于普通手机体验。退出当前页会提交保存任务，重开读取原子文件。未完成笔在取消/转屏/离开画布时不提交。

本机笔记存于App私有目录，卸载会删除。编辑页点击“导出”保存.ncp备份到系统文件位置；列表点击“导入备份”恢复为新笔记，可重复导入，不覆盖原件。请选择自己导出的NCPREVIEW v1文件，单文件最多32MiB；损坏、未知版本或保存失败会明确提示。取消文件选择器不会修改笔记。当前为预览格式，请先使用测试笔记。运行验证结果以匹配APK SHA的reports/android-smoke.json为准，真机触笔与性能仍待专门验证。

## iOS

工程：`ios-app/NoteCorePreview.xcodeproj`，共享Scheme `NoteCorePreview`，SwiftUI宿主与UIKit输入/画布。需要先生成共享framework再由Xcode构建。本轮已用Xcode27实际编译并链接ARM64模拟器.app，见[构建报告](../reports/ios-preview-build.json)；本机已安装iOS27.0 ARM64运行时，专用设备已创建；当前构建报告仅证明编译，启动证据另行记录。dist/NoteCore-0.1.0-preview-ios-simulator-arm64.app.zip是模拟器包，不是真机IPA。

```bash
./gradlew -PenableAppleTargets=true :shared-core:linkDebugFrameworkIosSimulatorArm64
xcodebuild -project ios-app/NoteCorePreview.xcodeproj -scheme NoteCorePreview \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath ios-app/build CODE_SIGNING_ALLOWED=NO build
```

也可设置JAVA_HOME后运行`bash ci/package-ios-preview.sh`；已手工安装固定Native工具链时可额外设置KOTLIN_NATIVE_HOME。

iOS界面也提供“导出”和“导入备份”，编译已通过，但尚无实际文件选择器运行证据。

本机已安装iOS27.0 Simulator runtime；模拟器.app与真机IPA是不同产物，真机安装需要独立device framework和有效签名。不得将无签名模拟器包称为可装iPhone的IPA。

## 本轮实际验收

Android在独立API36/arm64模拟器完成真实UI冒烟：安装、冷启动、新建/重命名、两色触摸笔迹、撤销/重做、手指开关、保存确认、已存采样数核对、强停重开与文件内容逐字节一致。报告见[android-smoke.json](../reports/android-smoke.json)，[截图](../reports/android-preview.png)。备份新增验证系统选择器导出逐字节一致、取消、重复导入为独立副本、损坏文件拒绝及原件保留。JVM22套209项测试通过（Core128、文档域81）；Android lint无错误，剩余2条工具/备份属性兼容建议未阻塞构建。

已验证的是模拟器触摸与正常文件重开；真实触笔、物理延迟、低内存/断电恢复、完整P0、正式C1门禁尚未通过。iOS已有独立安装/启动与首屏证据，书写、保存重开和文件选择器尚未验证。

## 缩放与定位

双指缩放/平移；关闭“手指书写”后单指也可拖动页面。可见工具栏提供“放大、缩小、适合页面”。缩放范围为适页的1–6倍，放大后仍按页面坐标保存笔迹。第二根手指进入会取消正在写的未完成手指笔画；已有触笔书写时，手指不移动页面。视口不随笔记保存，重开回到适页。详见[视口ADR](adr/0007-preview-viewport-input.md)。

Android另有3项窗口多指事件检查，见[android-viewport-smoke.json](../reports/android-viewport-smoke.json)；事件为合成，不能代替真机防误触与延迟结果。运行前构建`:android-app:assembleDebugAndroidTest`，再执行`python3 tools/android_viewport_smoke.py --serial emulator-5580 --adb /path/to/adb`。只对项目专用模拟器运行；常规冒烟验证另见android-smoke.json。

## 核心关闭增量

新增文档关闭与恢复责任交接参考模型，见[ADR-0008](adr/0008-document-close-and-recovery-handoff.md)。它统一输入/队列/资源的关闭条件，但尚未接入预览App的异步存储或原生GPU后端；本机保存已接入有界后端，见下方保存增量。CLOSED不代表磁盘已保存、进程重启恢复或正式C1门禁通过。本轮重新打包并回归现有Android流程，iOS已有独立启动报告，关闭/保存交互仍待验证。

## 有界执行器增量

JVM/Android核心新增真实串行worker与owner结果泵，当前JVM209项/22 suites，另有Android ART的executor_owner_worker检查，见[执行器设计](adr/0009-bounded-owner-worker-executor.md)。Android独立报告目前为3项多指窗口检查+1项真实线程+3项存储检查，完整应用回归为21项。App文件保存已换用有界后端；Apple执行器12项/IO6项在macOS运行，iOS宿主已有独立启动报告，此处线程/IO套件仍为macOS证据。

## 保存增量

双端保存已接入[有界账本/执行器](adr/0011-preview-owned-storage-pipeline.md)，失败内容可从列表重开并重试，旧在途回执不能抹掉新版本。关闭保存准入失败会保留当前页；Android活动owner跨Activity重建保留。列表只读有界标题头，不整页解码笔迹，读取失败不显示成“没有笔记”。Android写入额外显式同步与有界读回核对，已有真实rename失败反例。当前仍全页文本保存，完整分页、正式分块事务与断电恢复尚未实现。

## 分页根候选

shared-core框架现在统一导出canvas-core规范模型和[文档根/页目录](adr/0013-paged-document-root.md)，平台工程仍只链接一份框架。JVM当前209项，按Core128/文档域81分列。App仍提供单页体验；有界分页历史已在shared-core实现，v2 codec和UI尚未接入，这一编译节点不代表已能在App里翻页。

## 分页历史候选

DEV-024B有界delta撤销/重做已实现，见[ADR-0014](adr/0014-document-delta-history.md)。Android独立报告目前为9项，新增实际ART owner/worker历史拒绝与最后页undo/redo检查；该检查直接使用文档authority，不代表App分页UI已接入。两端产物重新编译，iOS已有独立启动报告，该历史特性尚未做iOS交互验证。

## 分页codec候选

[DEV-024C](adr/0015-paged-preview-codec.md)已实现有界v2交换与v1只读迁入，保留绘制顺序和全部规范字段。Android独立报告增至10项（含真实ART v2往返/header及v1时间迁入）；App仍使用单页v1保存流程，不能将codec报告称为已能在App中分页保存。iOS已在专用模拟器启动，codec/UI交互未因此验收。

## 分页会话候选

DEV-024D1已实现共享会话与全根capture，Android独立报告11项，新增真实ART页面选择、未完成笔取消、copy/delete/undo及内存重建。双端App尚未接分页界面/存储；本节不声称已经完成跨页文件保存重开。iOS当前产物已在专用模拟器启动，会话尚未接原生分页UI。

## 保存协议候选

[DEV-024D2](adr/0017-unified-preview-save-input.md)把同一账本移入shared-core，经封闭不可变输入接旧单页和分页snapshot。Android独立报告12项，包括实际v2双页写入/读回和阻挡目录失败保留/修复重试；旧App保存经adapter共用同一状态机。原生App仍单页v1，尚无分页UI/文件重开验收。
