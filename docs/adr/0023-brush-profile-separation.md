# ADR-0023：笔刷解释范围与候选 2 的采用边界

日期：2026-11-22。状态：DEV-036/C1 第 2 项局部决定已采用；正式几何版本和 C1 未冻结。

依据：起始 Core `dc25078433b1a6c60aeabf432026ba56e7d2e05e`，固定 C1 候选仍为 `b299742`。本决定面向 CN-02/03/04、ENG-09、DATA-03、INK-01。当前预览已支持 MONOLINE/HIGHLIGHTER；旧文档“普通 App 仅 MONOLINE”限于各自记录的版本，不能用于描述当前预览或扩展固定 SDK 候选。

## 已观察到的解释差异

| 范围 | 几何与颜色 | 版本责任 |
|---|---|---|
| 当前预览 | 等宽原生 round Path；HIGHLIGHTER 的 alpha 取 `floor(inputAlpha×0.5)`；不按压力改变宽度 | 预览 algorithmVersion 1；文件版本与算法版本分开，预览不是正式格式承诺 |
| `swept-discs-draft-1` oracle | 连续线性圆盘并集；压力半径 `width/2×(0.25+0.75×pressure)`；荧光 alpha 为归一化输入 alpha×0.25 | internal ruleId；借用 BrushSpec 的 1 作为实验入口，不是预览 1 的可互换实现 |
| `BrushGeometryBuilder` 候选 2 | 每点固定 16 边形，非重复位置以法向四边形连接；荧光 alpha 为 `min(inputAlpha,96)`；全部轮廓一次 NON_ZERO 填充 | 独立实验 algorithmVersion 2；不能作为 1 的兼容替代 |

[执行回执](../../reports/c1-brush-profile-decision-20261122/verification.json)保留原实现差分：

- 不透明荧光笔三者的 alpha 分别为 127/255、0.25、96/255；输入 alpha=32 时，预览为 16，候选 2 仍为 32。这不是光栅 AA 或取整差异。
- 宽度 128 单点的探针 `(62,12)` 满足 `62²+12²=3988<64²`，在圆内、在候选 2 多边形外。固定 16 边形的径向缺口 `64×(1-cos(π/16))` 约 1.23 场景单位，乘 4 后约 4.92 目标单位。目标单位还需宿主换算像素；没有进行 AA 或设备像素测量。
- 压力样本 `(0,0,p=0)→(10,0,p=1)`、宽度 8 的 `(5,2.6)` 在连续圆盘扫掠内，却在候选 2 的实际轮廓并集外；`(5,2.7)` 在 oracle 外。候选 2 的法向桥接与连续扫掠不是同一覆盖规则，增加圆盘边数不能单独消除该差异。

## 决定

1. **淘汰候选 2 直接晋升为圆盘扫掠生产实现的路线。** 其固定多边形和法向桥接改变了覆盖，原生坐标量化检查只能限制新增量化误差，不能证明圆盘近似或压感覆盖正确。保留该候选、黄金文件和原生适配作其自身规则的实验参考，不改历史测试或宣称原实现损坏。
2. **采用显式解释范围，淘汰仅改 algorithmVersion 的迁移。** 当前预览、oracle ruleId 与候选 2 分别保留身份。不得把解析 oracle 的 1 当预览支持声明，也不得把已存的 1 改成 2 后重新解释。现有 codec 对 2/未知算法的拒绝保持；SQLite 隔离迁入保留原正文、原算法与原信封，不新增隐式视觉转换。
3. **采用原始真实点及一次整笔覆盖的方向，暂不冻结正式数值规则。** 正式规则必须单独规定尾段、压力函数、同笔 union、对象顺序、透明度与颜色空间。任何与预览颜色/覆盖不同的规则都需新的明确身份和转换决策，不能覆盖已存内容的解释。正式压力体验和目标质量门槛继续等待物理条件。
4. **淘汰用 AA 容差掩盖几何差异的方案。** 几何覆盖、浮点量化、AA 边缘与颜色混合分别核对。本次探针是光栅化前的严格内外差异；既有原生图像结果只证明原报告负载，不晋升为任意缩放/颜色空间一致性。

## 剩余证据及执行顺序

1. 正式覆盖规则明确后，改进共同几何候选以符合该规则；优先处理压力扫掠外切包络和圆盘逼近误差，预算先准入，无法达到精度时显式拒绝，不能改点/加粗/少画。复用现有 oracle、几何结果和平台适配，不建第二 authority 或后台队列。
2. 按同一规则执行单点、急转/折返、跨段接缝、重复点、长笔、任意仿射/大坐标的几何对照；将像素误差阈值与目标 CTM、最大放大倍率绑定。之后才定正式算法编号/迁移。现有算法 2 的实验编号不复用。
3. 同一正式候选再验证双端实际后端的整笔 alpha、颜色与 AA 边缘；各自记录目标格式、色彩空间、CTM、平台版本及失败能力。物理压力体验、M-1 延迟/heap 和 S2/S9 设备索引成本另测。
4. 更新 C1 候选时列出受影响的 SDK/编解码/迁入/渲染消费者并复验。完整六项、最低 iOS 实际运行及物理门槛满足后才冻结 C1、接生产 SQLite。

此次测试在主机 JVM 执行原 common 实现和独立凸轮廓内外查询。没有 App 绘制、普通 OS 输入、Apple/ART 重编译运行、真实设备或生产格式验收。该决定关闭的是“候选 2 能否不经规则变更直接替代”的问题，正式几何交付仍待完成。

## 下一增量执行卡：自适应圆盘与外切连接

2026-11-22，DEV-036 第 2 项。目标是消除上面的圆点和压力桥接反例，并提供随完整对象/视口 CTM 换算的几何误差界。隔离实现使用独立 internal ruleId，不分配正式算法编号，不接 App 或 codec。继续借用不可变样本和原 BrushGeometry/BrushPathPlanner，不增加 Scene 或异步责任。

连续线性圆盘扫掠等于相邻端点圆盘的凸包。非包含情形采用两圆公外切线的四边形连接，包含/同心情形由圆盘并集覆盖。圆盘使用自适应内接多边形，按 CTM 线性部分范数的保守上界把目标容差反推到局部，控制径向缺口；所有轮廓同向并一次 NON_ZERO 填充。先完成顶点/字节计数再分配，退化/精度/容量不足明确拒绝。颜色暂沿当前预览半 alpha 的显式候选配置，与 oracle 的颜色规则独立，不能宣称其 alpha 兼容。

验收：确定的圆点/压力差异点纠正；以独立解析 oracle 检查覆盖及误差带；包含、重复点、反射/斜切/非均匀缩放和大坐标拒绝；精确预算边界及每项小一拒绝；原候选2和未知版本拒绝回归保持。先验证共同数值，再验证原路径规划和双端原生消费者；本次只对实际执行范围形成采用决定。

## 执行结果与采用范围

隔离 `SweptDiscGeometryPoc` 已实现上述连接和细分，ruleId 为 `swept-discs-tangent-adaptive-draft-1`。完整 JVM 731 项通过；API26 ART 与 iOS27 Simulator Kotlin/Native 各通过同一组选定 38 项（包含新候选6项、解释差分3项和原 oracle/几何/路径规划回归），均零跳过。两端只运行独立库测试，不安装当前预览 App。见[绑定源码、产物和原始日志的回执](../../reports/c1-swept-disc-20261122/verification.json)。

宽度128、四倍目标缩放的圆点使用128边形，报告的目标误差上界约0.10904（默认容差0.125），原圆内探针已被覆盖。压力外切连接覆盖原 `(5,2.6)` 反例，并拒绝外部 `(5,2.7)`。每个 runtime 对三类笔刷、三种线性变换执行33,489次固定网格分类；无观察到的越界覆盖，37个内侧缺口探针均在所报告带内。包含圆、重复点、样本保留、精确字节/顶点/样本额度和小一拒绝、不可表示与超精度拒绝均通过。临时模拟器清理后原设备清单保持。

**调整后采用为下一共同几何候选。** 这是对候选2直升路线的替换，不是新的公开算法版本。保留原 BrushGeometry 和 BrushPathPlanner，未接渲染/App/保存。几何误差的解析部分由内接圆盘缺口及 CTM Frobenius 范数界推导；数值 guard 用于主动拒绝明显不安全的消减范围，当前并未证明任意 Double 或平台三角函数的全部误差。新候选颜色明确沿当前预览半 alpha；oracle 只作覆盖参照，不把其四分之一 alpha 当颜色期望。

下一步复用原双端路径消费者验证同笔覆盖、颜色/AA、量化误差以及真实负载成本，并继续极端数值与完整变换审查。固定 C1 SDK 候选仍为 b299742；本内部候选没有晋升其签名、存储或设备验收。正式版本、M-1、最低 iOS 实际运行与生产 SQLite 门禁保持。

## 原生光栅消费执行卡

2026-11-22：在隔离构建中临时加入测试桥，复用原 Android NativeBrushRenderer 源码和 Swift NativeBrushRenderer 原类片段；生产源码/SDK/App 不增加桥接。固定六组负载：荧光折返、压感渐变、反射斜切、四倍宽圆点、大原点抵消、驻点压力变化。采集一次/两次整笔绘制的 RGBA、路径坐标、构建/原生准备/绘制分段耗时及显式像素存储，不把这些数值当设备 heap 或帧预算。

验收：同一组选定 FLOAT32 计划在两端消费，整笔与跨笔 alpha 分开核对；路径内部与外部清晰区域核对预乘颜色，AA 差异留在边缘并量化；报告实际像素差异，不以统一容差掩盖内部错误。平台 AA/颜色差异若阻止一致性则明确记录，不能宣布正式跨端像素支持。原 SDK 候选及生产接线不变。

## 原生光栅消费结果与决定

[双端回执](../../reports/c1-swept-disc-raster-20261122/verification.json)记录六组/每组一次与两次整笔绘制，共12对 RGBA。Android API26 独立库仪器进程使用原 NativeBrushRenderer 完整源码；iOS27 独立 Swift 进程使用原 NativeBrushRenderer 类片段，均与原源码绑定。公开测试桥只加入本次隔离构建，生产 SDK/App 不增加入口。两端 FLOAT32 计划的全部坐标/轮廓与 ARGB 完全一致。

首轮比较因测试位图 Y 轴配置失败：CoreGraphics 非透明边界按图像高度翻转后与 Android 对应。探针随后显式把 CGContext 配置为共同左上原点，实际重新绘制 Apple 输出；原几何/渲染器未改，已完成的 Android 输出保留。首轮源、失败、原 RGBA 和边界诊断都留在回执，不作为产品缺陷或通过结果。

最终75,828个清晰区域探针通过，颜色/alpha各通道相对预期误差最多2。探针包括每17像素抽样与所有跨端通道差大于2的像素；距任意轮廓边1.5像素内单列，包含重叠内部边，不等价于精确可见并集边界。选定荧光折返的内部 alpha 一次127、两笔191，未因同笔轮廓重叠变深。比较器的共同错误重复叠加、共同外部误涂、单端上下翻转和计划漂移反例均被拒绝。

**采用原生路径消费和同笔一次合成的已证范围；淘汰跨端原生 AA 逐像素相同的推断。** 实际最大通道差在不同负载为6–51，宽圆点两笔绘制最大51；差大于2的像素未超出上述轮廓带。本结果不把51设为正式质量容差，也不宣布 AA/颜色空间完整一致。正式边缘策略、可接受质量与缩略图/导出一致性继续待定。

分阶段耗时保留原始值，修正坐标后Apple 首组 build-plan约2.72ms、native-prepare约1.46ms、三次draw合计约2.86ms；其余负载和Android范围见回执。它们包含冷初始化且仅是微型合成负载，不能作为同机密集页或物理帧预算。单张显式像素存储为196,608或1,638,400字节，未包含原生Path、allocator、GPU或旧帧持有，不能当heap。

下一步以同一候选核对长笔/密集页与尾段的生成/原生准备成本，评审正式几何/AA及持久算法身份。固定C1候选、最低iOS实际运行、物理M-1/触笔/heap和完整六项门槛继续保持。

## 2026-11-24 长笔分段生成

采用固定128条相邻样本边的范围供几何按需生成，相邻段共用一个真实采样点，跨段的连接由后段生成。段内细分依据该段的最大半径、坐标范围与目标变换。只要笔刷参数、目标变换和误差预算一致，已满段的输入范围和几何就不依赖后续样本。最后一个未满段仍可在追加时重新生成。范围直接读取原不可变样本，生成器不复制采样数组，也不保留输出目录。

JVM 的 S9 夹具在四倍缩放下按三种笔刷分别生成782段并覆盖全部99,999条边，每段最多129点、10,000顶点、160,000逻辑字节。实测单段最高141,576字节。晚到高压点的共同测试逐顶点核对已满段，并检查共享端点及后段连接。见[验证回执](../../reports/c1-swept-segments-20261124/verification.json)。

采用范围仅限有界生成与稳定前缀。消费者需要按可见范围和总预算调度，对同笔所有可见段先合并覆盖再着色一次，独立验证跨段接缝、旋转和迟到帧。不能把逐段透明绘制当作合成。完整 S2 混排、原生长笔成本、实际 heap、最低 iOS 和 M-1 继续待验。

## 2026-11-24 分段覆盖合成

隔离入口 `ChunkedBrushPoc.renderSwept` 采用原分段目录、瓦片查询和子像素覆盖累加器。按当前目标像素尺寸选择几何细分，经过 FLOAT64 路径预检再合并覆盖。透明度取候选笔刷显示值，只在读取或合成整笔瓦片覆盖时应用。独立规则标识区分旧四分之一 alpha 参考路径与新候选的半 alpha。旧缓存和生产 App 不调用新入口。

一次瓦片工作受候选段数、累计生成顶点、累计覆盖边测试和峰值逻辑工作字节约束。工作字节计入覆盖数组、候选 ID 载荷和当前几何载荷。目录、源样本和平台分配器由各自责任方计量。拒绝或取消不返回局部瓦片。

验收核对同笔折返处 alpha、共享端点、相邻瓦片与宽瓦片逐子像素一致，以及候选数拒绝、精确预算准入与差一拒绝。采用范围为隔离软件瓦片。正式原生合成、旋转跨段、S2 混排和整页长笔工作负载的成本及物理 M-1 继续待测。见[回执](../../reports/c1-swept-tile-union-20261124/verification.json)。
