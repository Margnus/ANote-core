# ADR-0021：共同笔刷几何候选2

日期：2026-10-19。状态：M-2首个独立几何PoC，未冻结，尚未接原生后端或预览文件格式。

## 边界与版本

现有预览以algorithmVersion=1保存固定线宽折线。不能将新算法悄悄解释成旧算法；本次BrushGeometryBuilder只接受候选algorithmVersion=2，其他版本显式返回UNSUPPORTED_ALGORITHM。现有codec、会话工具和Android/Swift绘制不改动，原文件不会升级。候选2仍不是对外发布格式，未来接入必须有显式兼容决策。

## 几何规范

- 输入直接读取不可变StrokeSamples与BrushSpec，不创建第二份可编辑笔画，不修改或重采样真实点。原坐标均为局部场景坐标，先减第一个样本作为origin；输出double坐标相对origin，宿主之后统一应用对象/视口矩阵。
- 每个样本输出一个固定16边正多边形圆盘；每对位置不同的相邻样本输出一个连接两端法向半径的四边形。两者的并集定义笔迹区域。这是分段参考几何，没有拟合、简化、倾角或真实笔尖模拟；不声称为解析圆或两圆外公切线包络。
- 单点是一个圆盘。重复位置不产生零长连接，但每个样本仍生成圆盘，压力变大可扩大区域。尖角/折返以圆盘连接，不产生miter尖刺；输入顺序决定稳定的轮廓输出顺序。
- MONOLINE与HIGHLIGHTER半径为width/2。PRESSURE半径为width/2 × (0.25 + 0.75 × pressure)，pressure为原存储Float转Double，0压力仍保留可见端点。width是最大直径，不再额外加粗。
- 所有轮廓使用同一代数正向。每笔必须把全部轮廓加入同一路径，以NON_ZERO规则一次填充、SOURCE_OVER合成；不得逐轮廓独立着色，也不得even-odd填充。否则重叠处会加深或产生空洞。负行列式对象变换会同时反转所有轮廓，非零规则仍适用。
- MONOLINE/PRESSURE使用输入ARGB。HIGHLIGHTER将alpha限制到min(inputAlpha,96)，RGB不变；同一笔内部alpha不累积，不同笔按绘制顺序source-over。这里规定的是参数和区域语义，线性/sRGB混合、边缘抗锯齿及色彩管理尚待后端比较，不宣称像素一致。
- 圆盘方向使用固定double常量，无平台Path/cos/sin解释。黄金数值以绝对误差1e-9比较；尚未在Apple编译/执行，不能声称双端数值已实测一致。

## 预算、失败与所有权

先做完整计数/预算准入，再分配输出数组。默认最多20,000样本、400,000顶点、8MiB保守逻辑字节；逻辑charge包括坐标/轮廓偏移与固定开销，不是实际heap测量，也不包含调用方输入或原生路径副本。

输入样本超限、顶点超限、字节超限与不可表示数值均返回类型化拒绝，不返回部分几何。极小半径/大跨度导致轮廓退化时拒绝，不能擅自加粗、丢点或跳过连接。受理不产生内容revision或durable receipt。输出数组由builder私有持有，不向调用方泄漏可变引用；未发布前遇数值失败，局部数组随失败退出释放。

## 验证入口

commonTest覆盖笔宽/压力、单点/重复点、急转/折返、边界与预算拒绝、原输入/结果隔离和同笔非零并集语义。fixtures/brush包含固定输入与完整顶点黄金值，JVM测试核验manifest SHA后逐项比较；黄金值由规范独立计算并存储，测试不会从当前builder自动更新期望值。

实际验证结果见进度与reports/verification.json。M-2尚需原生统一填充、跨端几何/图像对照、绘制成本与增量尾段实验；固定16边形在大倍率下的近似误差尚未满足生产质量门禁。M-0/M-1/M-3、存储和C1继续独立验收。
