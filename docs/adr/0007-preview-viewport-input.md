# ADR-0007：共享视口与原生输入仲裁

2026-10-14；D4预览增量，改善页面缩放和定位，不冻结生产Scene/渲染协议。

## 视口模型

PreviewViewport只维护UI owner的width/height、相对适页zoom及平移。页面仍是1000×1400，实际scale=fitScale×zoom，zoom限制1–6倍。渲染与输入均使用同一scale/offset进行正逆映射，不重写笔迹坐标/粗细/内容revision，不触发文档保存或几何Path重建。视口是可丢弃呈现状态，不写NCPREVIEW备份；重开回到适合页面。

捏合将前一质心下的scene点映射到当前质心，实现同一操作内缩放与平移。页面小于视口时居中，大于视口时限制平移，页面不能完全拖出。边缘约束可能改变焦点锚定，这是防止页面丢失的明确取舍。尺寸变化前取消未完成笔，再尽量保留页面中心与zoom；回到适页可显式复位。非法手势和零尺寸不产生变换；尺寸/坐标有有限范围防止数值溢出。

## 输入仲裁

- 手指书写开启：单指写字；第二根手指进入时取消未完成手指笔画，开始双指缩放/平移。已完成笔迹保留。
- 手指书写关闭：单指平移、双指缩放，触笔仍能写字。
- 导航进入后，本次接触序列剩余手指继续导航，不切回书写；全部离开后下一次接触重新判定。指针变化时重建质心基线，避免跳变。
- 已有触笔笔画期间忽略其他手指的导航，保持当前坐标变换固定；触笔结束后若仍有手指，等待手指离开再开始下一次序列。此规则不等于设备级防误触认证。
- 点击工具、复位、尺寸变化或detach会取消未完成笔画。仅视口变化不提交/删除已接受内容。

Android依据[MotionEvent指针身份与多点事件](https://developer.android.com/develop/ui/views/touch-and-input/gestures/multi)处理pointerId、POINTER_DOWN/UP与真实历史点。iOS在UIKit touch回调中按真实UITouch身份/质心处理；合成/预测不进入规范采样。当前不含旋转手势、惯性、双击缩放、跨文档视口记忆或生产级全局手掌识别。

## 验证

公共测试覆盖适页/复位、焦点保持、平移与缩放边界、非法输入、尺寸恢复及1000组固定seed正逆映射。Android专用Instrumentation通过UiAutomation将多指/触笔MotionEvent注入实际窗口，验证取消临时手指笔画、缩放后落笔坐标、复位不改文档、触笔变换锁与单指平移不落墨。测试使用内存测试笔记，不改用户已有笔记。

报告android-viewport-smoke.json记录被安装APK、测试APK和源码hash；事件明确为合成，不声称真机触笔/性能已验证。常规android-smoke.json继续覆盖真实窗口触摸、保存重开、备份和视口工具栏。iOS继续只有模拟器编译证据，没有runtime启动证据。下一步回到D3关闭协调/恢复handoff，再推进完整分页、分块存储与设备性能基线。
