# 输入与派生暂存责任模型

2026-10-25。C1第1项的当前源代码责任清点，补充[保存派发与预算契约](保存派发与预算契约.md)。所有数值均区分源码载荷、逻辑预留和未知平台分配；本模型未证明完整峰值准入或设备heap上限。输入限额不会反向限制操作系统已经交付的事件内部存储。

## 一次输入回调的同时存活关系

令本次真实点数为n（原双端入口在应用数组构建前检查n≤1024），本笔容量为c（最多20000），当前已接收为k。四种规范标量为Double x/y、Float压力、Int64时间，每点载荷28字节。下表描述源码显式创建/保留的容器，不估算对象头、容量舍入、ARC/GC回收延迟或运行时跨语言复制。

| 路径/阶段 | 同时仍有责任的内容 | 上界/结束条件 |
|---|---|---|
| Android原MotionEvent回调 | 平台原事件＋四个primitive数组＋原arena/完成命令 | 应用producer载荷28n≤28672字节；原数组同步传入原Notebook，无逐点InputSample或第二组Kotlin数组；回调返回不保留事件/数组，规范样本已复制。平台历史/多pointer原事件内部大小未知 |
| Apple realSamples | UIKit原事件/coalesced触摸数组＋n个RealSample＋原arena | RealSample容器为n×MemoryLayout<RealSample>.stride，平台布局/容量/头部不由28n表示。只保留活动主touch供序列身份识别，辅助触摸不存入会话。UIKit返回coalesced数组本身在应用检查数量之前已经存在 |
| Apple Data准备/同步桥接 | 同一RealSample数组＋四份Data＋可能的Foundation桥接存储＋四个Kotlin数组＋原arena/完成命令 | Data声明载荷28n，Kotlin数组载荷28n；Foundation桥接是否共享/复制与额外容量不能从源码认定。当前直接从RealSample填Data，已移除四次map数组，不假定旧map临时全部同时存活，也不声称测得heap下降 |
| 原Notebook DOWN/MOVE | 当前root/历史/journal/identity＋producer仍在调用栈上的容器＋arena | inputBytes只约束原Notebook输入所有权，不包括调用者producer。当前arena预留含最多两份28c载荷、分块/固定开销，外加3072命令元数据；c=20000为1133696。不能将inputBytes=2MiB当成整个回调2MiB上限 |
| 原UP/未知提交失败 | producer容器仍在栈上；分块arena与新规范数组曾重叠；完整命令或pending；可能进入提交投影 | finish把新数组唯一交给StrokeSamples并清原chunks；后续pending按2048＋2×四身份长度＋28k逻辑计费。源码清引用不是实际heap立即回收。提交成功后的root/journal/history仍各有保留责任 |

1024点和1025点的原UIKit回调消费者、逐标量位模式/源对象事后变更与后续书写，见[producer报告](../reports/producer-scratch.json)。合成UITouch不是OS输入或Pencil测量。Android当前原宿主证据仅沿用其对应源码/包的既有报告，本轮未重新运行Android。

## 采用结论和剩余门禁

采用原Swift producer直接填四个Data，保留原UIKit校验、原同步NSData→Kotlin数组复制、唯一arena/authority与保存路径。本次清点并未让所有独立逻辑预算共享一个总上限；不创建第二账本来显示一个无法执行的“总额度”。

原库列表作业/结果现在已有共享的明确逻辑模型，见[列表报告](../reports/catalog-budget.json)：非空结果为512＋512×行数＋2×所有ID/显示标题UTF16单位；空结果0。最长2008行声明2044656字节，低于默认2MiB。work为65536＋2×2097152＋2000×(2048＋8×(目录路径UTF16单位＋133))，预留应用可控路径/URL/ID暂存、单头工作区和旧新结果重叠。固定开销是显式政策，不是由公式证明的真实对象头/平台heap。

两端在合并/排序前检查完整候选，不发布部分列表；枚举2001条的容量拒绝和真实IO/unknown分开，拒绝保留旧列表、原文件和原ledger。已完成Data/元数据在ACK后的独立保留者已补齐各自额度，但跨模块总预算仍没有共同原子准入；不能相加全部分项quota并称物理heap上限。Foundation/系统枚举器/Path/GPU/SwiftUI或外部回调持有仍可能超出应用声明，GC/ARC释放滞后也未测。
