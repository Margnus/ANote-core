# OBJ-03 编码图片与方向接缝

## 交付卡（2026-10-29）

起点Core fdd9ef3。目标：真实JPEG/PNG字节→Android主机原生BitmapFactory→实际编译的internal方向矩阵→Canvas，验证方向只应用一次及透明alpha保持。复用Robolectric SDK35/原Affine2D，不新增解码器依赖/SDK/authority或App功能；原图作为只读输入，输出仅build。

验收：独立Pillow生成2×3不对称色块，JPEG/透明RGBA PNG各8个EXIF方向，固定fixture/manifest入库。Android检查解码后的原始尺寸和原始像素，不能仅凭宽高判断是否自动旋转；将实际共享映射转Android Matrix并在Canvas绘制，与Pillow独立定向期望的全部色块中心比较。alpha精确，非透明RGB容差3，完全透明不比较无语义RGB。源文件前后hash一致，Bitmap释放，PNG留build并查看。

测试反射只调用实际internal规则，不复制规则或扩大公开SDK。结论限当前主机Robolectric native BitmapFactory/Canvas、8位RGB/RGBA合成样本；不是ART/Apple/真实用户图/ICC/高位深或生产导入。即使通过，也必须在实际平台adapter核对EXIF/解码器自动方向、按视口解码/资源预算，不能假定所有解码API都忽略方向。OBJ-03仍未开发/待验收，DATA-05/M-1/C1/DEV-041不变。
