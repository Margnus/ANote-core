# M-2B：有界共同路径与原生离屏差分

2026-10-15，DEV-028，接续[解析覆盖oracle](共同笔刷几何PoC.md)。此次交付实验路径输出、两端离屏消费者和S2/S9桌面成本证据；不接入App笔刷、不变更备份协议，也不冻结渲染后端。

## 输出选择与边界

BrushPathPoc把每个真实样本转为内接圆多边形，把相邻变半径圆盘之间的外切区域转为四边形；相同中心/包含关系不生成退化外切桥。半径、端点及alpha沿用swept-discs-draft-1。圆分段按sceneTolerance和仿射矩阵Frobenius范数上界计算，默认0.05场景单位，最少8边、最多4096边；达不到误差/容量要求时拒绝，不能静默降低质量或抽掉真实样本。该误差预算针对曲线多边形化；大坐标浮点误差、原生Float精度与像素滤波仍须单独测量，不能由数学误差界直接推成平台像素保证。

所有轮廓方向一致，反射后全部一起翻转。消费者必须在同一路径内以nonzero winding **一次填充**，不逐轮廓draw、不使用even-odd。重叠处是并集，荧光笔只应用一次alpha；不同笔画仍依规范z序独立合成。几何输出只是派生数据，不拥有Scene、页面目录、输入队列或内容revision。

内部输出为私有Double坐标数组与Int轮廓offset，按只读getter访问；没有共享可变数组。默认每次最多500,000顶点/16MiB逻辑输出，最多200,000样本；分配大数组前预扫顶点数、字节数、分段精度和坐标范围。未知版本、奇异变换、不可满足的误差/预算显式Rejected；取消在预扫、分配前、生成中及返回前检查，只返回Cancelled，不发布半条路径。原始StrokeSamples仍由调用方持有，拒绝/取消不改变原始内容或保存状态。

这不是全局内存/执行器预算：并发数、路径对象头、临时原生Path、mask/纹理与过期结果释放尚未整合。未来派生输出须沿用已有FramePublicationGate/资源所有权，绑定文档/页/对象修订与几何规则/容差，不新建另一份可变规范模型。

## 正确性参照与平台消费者

四项新增common测试使用独立解析oracle核对多边形覆盖与内点，覆盖急转、自交、变压、反射/斜切、包含圆盘、轮廓方向、容量/字节准入及生成中取消。原三组手工黄金格点继续通过。

共享JVM当前231项/26 suites通过。另由[工具](../tools/verify_apple_brush_common.py)实际编译并通过simctl spawn运行Kotlin/Native ARM64测试二进制，11项oracle/路径测试通过，见[报告](../reports/apple-brush-common-tests.json)。这证明共同算法在Kotlin/Native运行；下面的iOS原生光栅差分仍是另一套独立证据，不混成一个平台总分。

`generateBrushPathFixtures`把实际共同路径输出成[六组夹具](../fixtures/geometry/brush-paths.json)：圆线急转、压力渐变、荧光笔回折、包含圆盘、仿射反射、半透明荧光笔自交。期望mask由上一轮解析oracle生成，输出不是拿本次多边形点内算法作为期望。夹具记录源码UTF-8/LF指纹；Android测试APK和iOS测试bundle内的夹具须与源文件原字节相等，防止新报告引用旧资源。

Android消费者运行在专用模拟器ART，用Bitmap/Canvas/Path。Apple消费者运行在真正iOS Simulator app-host XCTest，用CoreGraphics；不使用macOS脚本替代iOS结果。两者均画一条复合路径，逐点核对透明背景下alpha。每个消费者在AA开/关两种模式核对43,256个稳定区域像素。解析边缘附近的格点显式标为`?`，此次**没有证明AA边缘逐像素一致**。测试只证明实际共同输出能被两端离屏绘制器消费，不证明App已启用三笔刷或平台运行时已现场生成本夹具。

Apple首轮失败来自测试适配漏掉位图行方向转换。独立macOS CoreGraphics诊断仅用于定位：直接行序4,033个差异，垂直反向行序0。修正iOS测试的top-down场景→bitmap坐标变换后重新执行真实iOS XCTest；不改变几何、不放宽alpha断言、不改期望mask。macOS诊断不计入iOS通过项。

## 可重跑入口

共享测试仍用`bash ci/verify.sh`。另可按顺序运行：

```bash
./gradlew :canvas-core:generateBrushPathFixtures
./gradlew :canvas-core:runBrushPathCosts :canvas-core:runSpatialIndexPoc
./gradlew -PenableAndroidTargets=true :android-app:verifyBrushPathTestBuild
python3 tools/verify_brush_paths_android.py --serial emulator-5580 --adb /path/to/adb
bash ci/package-ios-preview.sh
python3 tools/verify_apple_brush_common.py --device <专用模拟器UDID>
python3 tools/verify_ios_host.py --device <专用模拟器UDID>
python3 tools/ios_runtime_smoke.py --device <专用模拟器UDID>
```

按本工程说明设置JAVA_HOME、GRADLE_USER_HOME、ANDROID_HOME、PYTHON_BIN和可选KOTLIN_NATIVE_HOME；工具不要求特定机器的JDK绝对路径。iOS host测试使用独立构建目录，结束后runtime smoke恢复普通交付包。这里不创建、擦除或删除其他设备，不操作个人文档。

## 成本实验与架构影响

[成本报告](../reports/brush-path-costs.json)从hash核验的S2二进制逐笔读取100点，共10,000笔/百万点；分别为三笔刷构建路径，初笔预热100次。每笔时钟只覆盖路径构建/输出分配，排除fixture IO和样本复制；JIT/GC共享，单遍探索不是独立重复统计，更不是移动端渲染或触笔延迟。

| 笔刷 | 全部输出顶点总数 | 累计输出逻辑字节 | 单笔最大逻辑字节 |
|---|---:|---:|---:|
| MONOLINE | 30,960,000 | 503,360,000 | 50,336 |
| PRESSURE | 24,740,000 | 403,600,000 | 40,360 |
| HIGHLIGHTER | 30,960,000 | 503,360,000 | 50,336 |

当前逐笔用完即释放，不持有整个页面。累计约385–480MiB是“若所有输出都保留”的逻辑载荷风险线索，**不是实际heap/峰值测量**。它明确排除了整页无限制缓存所有路径的做法；默认500k顶点也使S9十万点长笔返回output-budget，100,000真实样本仍保留。当前适配不能把这种拒绝当成可正常显示长笔。

下一步先比较：按段/按块有界生成、可验证误差的派生几何简化、端点/转角按需圆盘和局部缓存；不能删改规范真实样本来降低几何成本。测量应同时记录分段接缝与union alpha、旧revision取消、临时/驻留/退休原生载荷和重建成本，再用相同几何边界比较对象索引与分段索引。未有这些证据前，不选择最终mesh/path/mask后端，不增加空模块，也不冻结C1。
