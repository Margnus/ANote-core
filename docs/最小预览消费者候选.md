# 最小预览消费者候选

2026-10-30，按现行计划B/C1第3项选择现有实际消费者入口。候选来自Android NoteStore/InkCanvasView、Swift PreviewModel/InkUIView及独立SketchSession/SketchView；采用唯一Notebook/authority及原owner/worker/pool，不新增façade。以下是预览集成的推荐范围，尚未冻结为正式SDK；全部ObjC导出、底层构造器和实验类不因此获得支持承诺。113条原需求范围不变。

| 采用的候选入口 | 宿主调用条件及结果责任 | 当前证据与剩余范围 |
|---|---|---|
| `createValidated/open/openRecovery` | 显式传同一串行owner检查，预先构造合法DocumentBudget。raw内容/容量拒绝检查`failure`，失败不采用Notebook；恢复保留完整pending，不能退回base。默认空owner回调不是线程保护。 | 原双端创建/读取/恢复消费者及共同测试；不是任意预算/值构造或错误线程均可恢复。 |
| `PreviewDocumentReader.read/accept`、`PreviewRecoveryCodec.read` | 纯内存内容检查。平台先执行文件字节、UTF转换和worker额度准入；完整成功才采用root/checkpoint。 | 原非法格式/不支持笔刷/恢复拒绝消费者；不代表生产格式、IO或durable回执。 |
| `edit(PreviewEdit)` | raw编辑参数走现有验证；accepted可能只是工具/展示/no-op，revision不是保存回执。拒绝检查failure，不静默取消真实输入或重发完成命令。 | 原双端typed编辑及独立宿主；旧Boolean编辑方法保留兼容，不作为新增集成的推荐入口。 |
| `prepareRealBatch/offerRealBatch` | 同owner、同步数组且调用期间不并发改写；prepare的null不是预留。REJECTED接收0新点，原前缀保留；PENDING_COMMIT归Notebook，禁止重发UP。 | 原真实历史采样/Swift批次桥与共同反例；系统事件、Pencil预测和物理输入仍按独立证据。 |
| `isReadOnly/setReadOnly` | 使用Notebook原模式，不复制宿主Boolean；活动前缀或pending阻止切换。只读限制内容修改，选页/工具按原契约允许。显式模式切换不构成授权ACL。 | 已复现并修复独立宿主绕过；当前Native/Swift公开模式实际验证见原只读回执。 |
| `page/stroke/point*`及状态读取 | 活动会话仍同owner，下标先按当前pageCount/strokeCount/pointCount检查；异步任务只捕获不可变root，不能带旧下标跨编辑解释。 | 两端实际渲染消费者；下标/owner是程序前置，不承诺NSError可恢复。 |
| `capture/captureRecovery/snapshot` | snapshot/capture仅已提交root；完整保存责任使用captureRecovery，活动笔迹不是checkpoint。编码/IO由原宿主有界worker执行，成功IO才显示已保存。 | 原双端保存/失败重试/已确认后重开；完整资源备份、未确认替换窗口和断电仍待。 |
| `retire/retireAfterRecovery` | 原owner停止新输入，pending须重试或先收到精确checkpoint的IO回执。后者只验证身份，不自行证明IO；原ledger/worker/native读者仍须drain。 | 原双端退休/迟到回执子范围；完全owner失联、活跃会话跨线程迁移及长期未signal不被支持为自动接管。 |
| 独立宿主`PageBackground` | Canvas仅在回调期间借用，不能保留；原View隔离背景变换/裁剪后画规范笔迹，并在退出时恢复页状态。 | 实际translate/clip污染反例及修复见[报告](../reports/sketch-background/report.json)；仅Android内存样例，不是生产资源port。 |

可信构造器、底层codec `decode/encode`、header、MemoryDocumentAuthority/命令构造和实验render类型不进入这份推荐调用清单。它们继续有其原API和程序前置，不做破坏性移除；header可供有界列表展示，不能作为正文采用许可。合法值对象仍是候选入口的依赖，不能把其require或owner回调错误包装成内容损坏。

采用依据：原[只读双端回执](../reports/sketch-readonly/apple-verification.json)包含固定6b1c155的Native211/306、Swift50及普通UI链；[当前Android独立验证](当前Android独立环境验证.md)保留Provider/配置/进程等各自来源；[C1既有前置条件表](C1未决事项.md)保留具体调用语义。测试数不证明完整参数/OS矩阵，以上选择没有重绑旧报告。

关闭C1第3项还需要正式SDK暴露面与此清单对齐、明确依赖值对象和平台资源/渲染port的支持范围，并对最终选定签名完成双端适用conformance。当前只能采用这份候选调用路径及已经实际执行的子范围；完整白名单、其余C1六项和物理M-1未齐时不冻结架构、不接生产SQLite。下一工作对照这些具体剩余条件推进，不能再以增加相同模式或背景happy path延长阶段。
