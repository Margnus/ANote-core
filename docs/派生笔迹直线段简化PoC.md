# M-2C：不改规范采样的直线段简化

2026-10-15，DEV-029。针对[DEV-028](共同笔刷路径与离屏验证.md)的S2累计路径载荷约385–480MiB，新增独立可选ReducedBrushPathPoc；基线BrushPathPoc及六组原生夹具不变。新路径未接入App，不能把DEV-028的原生光栅结果算成简化器已在原生验证。

## 规则与证明范围

只删除派生几何中的可证明冗余中间点，不修改StrokeSamples、时间/压力、文档根、undo或文件。计划是一组绑定原StrokeSamples实例、brush kind/版本的只读索引，首末点保留；无法可靠判定的点原样进入几何。

设A、B、C沿同一直线同方向，B位于AC之间。若半径随位置线性变化，扫掠AB与BC的圆盘并集正好是扫掠AC的同一集合。MONOLINE/HIGHLIGHTER半径恒定；PRESSURE必须另外证明压力与位置线性，因为当前半径规则对压力是仿射函数。**只检查压力落在端点范围内不充分**：删除中间压力谷会扩张覆盖，删除压力峰会缩小覆盖，二者都必须保留。相邻完全相同圆盘可消除重复派生输入，但原始采样仍保留。

不使用浮点epsilon猜测共线。仅当坐标能精确表示为1/1024网格、量化值绝对值≤1,000,000,000时，才用Long叉积/点积判断共线且不反向。差值≤2e9，单个乘积≤4e18，两项和/差≤8e18，低于Long.MAX。压力另要求能精确表示为1/65536网格；压力差与坐标差的乘积也在Long范围。非网格、大坐标、转角、回折、压力突变全部回退保留。数学覆盖集合等价不等于浮点或原生AA像素逐位相同，多边形化误差与平台精度门禁仍独立存在。

采用栈式单遍计划，每个索引最多入栈/移除一次，O(N)。默认最多200,000样本/1MiB计划；数组按原点数一次分配、不复制缩容，logicalBytes如实计入全部索引容量。可在扫描中取消，只返回Cancelled；不会发布部分计划。

## 路径生成与预算

如果一个点也不能省，直接把原样本传给基线生成器；否则创建短命的派生几何输入副本，再调用同一基线。此副本不成为另一份Scene或持久化数据，不可拿它替换原笔迹。源实例匹配和kind/版本校验防止计划用于其他输入。

默认16MiB每调用派生工作预算包括计划数组、两份投影数组（创建数组及StrokeSamples防御副本）与最终路径载荷；投影分配前准入，不够就显式失败。原本已拥有的规范采样、对象头、GC、原生Path/mask/纹理和并发总量不在此逻辑值内，不能把它当进程heap峰值或全局资源预算。取消在计划、投影及基线生成阶段贯穿，原始点继续由调用方持有。
