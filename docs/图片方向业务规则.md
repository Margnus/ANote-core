# OBJ-03 图片方向规则

## 交付卡（2026-10-29）

起点Core512feb2，两仓fetch一致。真实源检查仅覆盖EXIF方向1；本轮补原图不变的八方向坐标规则，复用原Affine2D，internal且无IO/解码器/authority/格式或App入口。目标：原始解码栅格到正确显示方向的双向坐标，不把方向修正写回原图；源像素尺寸/方向不变，5..8交换输出宽高。

验收：八方向按栅格左上原点/y向下、边界坐标0..width/height定义，像素中心为x+.5/y+.5。独立2×3标号格点oracle检查每个像素位置，四角包络和逆映射检查；未知方向/无效尺寸/预算显式拒绝。像素数用Long乘法，默认3200万仅沿用既有样本检查准入而非产品支持上限，可由调用者明确给预算，拒绝不能静默降采样/裁剪。

方向约定：1原样、2水平镜像、3转180、4垂直镜像、5主对角转置、6顺时针90、7副对角转置、8顺时针270。输入宽高必须为方向修正前的原始栅格。缺失EXIF时adapter传1；未知值拒绝，不自动当1。解码器若已自动应用EXIF必须使用其已定向尺寸并传1，不能重复矩阵；adapter须实证，不以本规则推断平台行为。

采用后仍需PNG/JPEG实际解码/EXIF/ICC/alpha及原图hash保留、按视口解码预算、正式Image对象/变换/撤销及资源事务、双端UI/保存重开。规则只映射，不重采样或修改alpha，不是这部分能力已实现。OBJ-03仍未开发/待验收，DATA-05/M-1/C1/DEV-041不变。
