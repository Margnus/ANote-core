## 唯一责任链

原notebook捕获不可变PagedPreviewSnapshot，原PreviewSaveLedger持有最新快照及每个文档唯一旧flight；原BoundedOwnerExecutor/AppleBoundedOwnerExecutor执行编码/平台IO。派发不新建队列、worker或内容authority。ledger的32MiB快照额度与worker的256MiB声明工作额度分别保留；旧flight与较新latest同时计费，不能用较新root替代正在执行的旧输入。

Android NoteStore与Swift PreviewModel在同一owner读取原worker状态，调用admitNextWrite(availableWorkBytes, maximumWorkBytes, backendAccepting)，READY后再调用原executor.submit。worker槽位/停止等第二道拒绝仍须returnUnstarted；此时没有执行IO，不记磁盘失败或已保存。接受的任务及返回结果直到真实matching completion/ACK之前保持原责任。

## 派发结果

| disposition | attempt/状态变化 | 宿主责任 |
|---|---|---|
| READY | 唯一attempt，分配序号并标该文档flight | 原worker准入；拒绝必须退还，完成按原attempt结算 |
| IDLE | 无新attempt；可能仍有flight或需显式重试的失败内容 | 不能当作已保存或全部drained |
| BACKPRESSURE | 无新attempt，不消耗序号，不修改flight/latest | 等既有worker进展再pump，内容仍由ledger持有 |
| WORK_CAPACITY | 当前可派发文档都超过单任务最大额度；无attempt | 明确容量错误并保留内容，不伪装等待后会自行恢复 |
| BACKEND_UNAVAILABLE | 有待派发内容但worker不再接受；无attempt | 明确后端不可用，不能误报为暂时字节背压；已在途IO仍可正常完成 |
| INVALID_BUDGET | 负available、非正maximum或available大于maximum；无attempt | 明确配置/输入失败并保留内容，不隐藏为成功 |
| IDENTITY_EXHAUSTED | 不再分配attempt，所有快照保留 | 明确后端身份耗尽，不抛出跨语言未声明的check异常 |

只跳过永久超过maximum的文档，让其他可执行文档继续保存；暂时超出available但可放入maximum的首个文档保留顺序，避免持续小保存让它饿死。同文档永远只一个flight，新的完整root留在latest，旧completion不能清空它。跨文档不是文档命令的全局提交顺序。

失败/未知IO保持快照并要求显式offer重试；较新完整快照仍可替换未开始/失败旧内容。重送不重跑已确认成功的旧attempt；returnUnstarted和complete都要求ledger身份与当前flight对象完全匹配，旧/外来attempt返回false。派发READY或Boolean保存入口受理不产生durable回执，App保存成功仍来自实际平台IO完成。

## owner与公开边界

ledger构造、查询及所有状态修改都先调用ownerCheck。Android绑定原executor.checkOwnerThread；Swift绑定原主线程检查。owner/程序回调异常原样传播，不转为容量失败。兼容构造默认空检查与nextWrite()只为既有可信调用方保留，不构成线程安全保证；实际双端App使用typed入口及显式owner检查。

本次没有冻结公共SDK、隐藏所有内部导出或提供任意不可信root factory。Snapshot为既有closed不可变类型，编码工作量由原codec计算；available/maximum是原worker同owner的即时观察，不是跨线程reservation。原executor仍是实际任务/额度准入权威。
