# 旧DrawPanel字段与迁移候选规则

2026-10-14；C1候选，尚无生产转换器。范围为本地DrawPanel源码、国内App的proto/Converter与Stroke外层。证据在[源码声明快照](../fixtures/legacy/source-schema.json)：15个文件hash、12个定位锚点、模型/JSON别名、proto字段号与笔种常量。可运行`python3 tools/snapshot_legacy_schema.py`重新核对相邻源码；独立克隆不需要旧工程即可运行新原型。快照扫描为受限文本解析，不能替代AST或AAR等价验证。

## 必须按来源识别版本

| 来源 | 识别与默认值 | 候选处理 |
|---|---|---|
| 原始DrawRecord/PressurePoint JSON | 短key与alternate长key；原类构造默认与历史反序列化默认可能不同 | 显式选择对应版本schema；冲突key拒绝，不猜测哪一个优先 |
| compact V1 | `sv=1&pv=1&`及StoreDrawRecord/StorePressurePoint位字段 | 单独compatibility decoder，未知sv/pv保留原payload并停止转换 |
| 无sv头历史数据 | 源码返回(0,0,data)，并不证明任何无头内容就是有效JSON | 单独检测容器/版本，无法识别则保留原包并报告 |
| 国内App proto | DrawRecordWrapper、PressurePointWrapper均optional；外层Room Stroke带page/layer/id/index | 使用字段presence及实际Converter默认规则；外层信息不可丢 |
| Parcelable/Java Serializable | 顺序、serialVersionUID与缺字段规则有别 | 首发不执行任意旧对象反序列化；需要独立工具与合法黄金样本验证 |

## 点字段（完整字段处置）

| 旧字段 | 含义/事实 | 新组件候选位置与边界 |
|---|---|---|
| x/y | Float；compact坐标舍入两位小数；proto号1/2 | 保留已存数值，再提升double；须知道页坐标/局部原点，不能恢复丢失精度 |
| p | proto号3；默认坐标策略取MotionEvent.pressure，缺事件用0.01 | 旧pressure原值与来源保留；不静默clamp成0–1，设备归一规则需另定 |
| action | JSON a/action；源码约定down=0/up=1/move=2，proto号4 | 转为旧点语义；它没有完整pointer/timestamp/CANCEL，不能直接构造真实设备事件 |
| velocity | JSON b/velocity但Expose serialize=false且Transient | 可重算派生量或保留原始扩展；不作为规范真实采样 |
| lastType/nextType | JSON c/d；proto5/6；0可见、1隐藏 | 保留分段拓扑/擦除语义，不能简单删除隐藏点并连线 |
| mSoundPosition | JSON e；proto7，录音位置毫秒 | 音频锚点扩展；**不是触笔采样时间**，不可乘1000冒充输入时钟 |
| mPointFlag | JSON f/mFillFlag；proto8；默认-1，其他值区分图形/虚线 | 版本化几何拓扑/控制点扩展；未知flag保留，不能当普通笔抹掉 |
| bmType/pencilW/pencilH | JSON g/h/i；proto9/10/11；默认-1 | 铅笔stamp资源/尺寸扩展；compact V1未保存这些字段，不可宣称可恢复 |
| rotation/tilt/angle | JSON j/k/l；proto12/13只含rotation/tilt | 旧铅笔几何参数；angle没有proto字段，copy/Parcel路径也未复制/写出；单位/校准另核对 |
| alpha | JSON m；proto14 | ctor默认1，当前Converter缺字段取0；必须按来源版本保留这个差异，不能一律补1或套用proto标量0 |
| 输入time/pointer/prediction | 上述持久化格式无这些字段 | time明确unknown；静态导入模型必须允许没有事件时钟。当前StrokeSamples强制Long时间，生产导入不能通过伪造时间绕过，需要C1调整 |

## 笔画字段（完整字段处置）

| 旧字段 | 新候选规则 |
|---|---|
| type/graphType | 按命名空间和来源版本判断，不把相同整数直接映射。BALLPOINT=1、INK=2、MARK=3可作为三笔候选，但视觉算法版本需黄金对照。IMAGE与GEOMETRY_LINE均为21，PDF与GEOMETRY_DOTTED均为22；不能只看一个type数值 |
| color/width | 保留ARGB与原width；compact width为8位十分之一量化。0宽/非法宽显式报告，不自动扩大 |
| id/strokeId | 原字符串与外层数据库ID独立保留；新ObjectId按来源doc/page/原ID稳定映射，缺失/重复用确定性迁移映射表，不能每次随机重生 |
| editEnable/showFill | 按来源默认值与presence；compact editEnable/showFill对应位0表示true，和普通Boolean直觉相反；图形能力扩展 |
| points/controlPoints | 真实点与图形控制点分离，保留顺序/分段；不把控制点当手写采样 |
| mSoundId/mDownSoundPosition/mUpSoundPosition | 宿主音频关联扩展，起止默认-1，均非输入clock |

## compact V1位规则与风险

PointBitV1：sp低7位为`(p*100).toInt()`，getP再除100；高位通过有符号shr7取得录音毫秒。源码无范围保护，超范围pressure或录音可串位/变负，注释所称4小时不是通用保证。m低3位action、bit3/4 last/next；bit5为flag=-1哨兵，否则bit6–10存flag。不能按StorePressurePoint注释的“总共10位”猜布局，实际代码是依据。

DrawRecordBitV1：type低6位；graphType占bit6–11且bit11是-1哨兵，因此合法正值应限制0–31而非把全部6位当任意值；width bit12–19，editEnable bit20、showFill bit21均反向，markLayer bit22–23。createT未掩码校验，越界可以污染相邻字段。compact仅存所列字段，不能由它恢复原始铅笔贴图参数、layerId或胶带信息。

## 进入生产迁移前的门禁

1. 在独立compatibility模块定义保留unknown时间/资源/对象的规范导入DTO，再讨论转换为Scene；公共输入状态机不承担格式猜测。
2. 用人工合成黄金包覆盖短/长key冲突、presence缺失、每个笔种/图形/擦除分段、compact边界和外层layer，核对源renderer与reference geometry。真实个人笔记不作为本阶段样本。
3. 记录文件/算法来源版本与损失清单；无法恢复的字段保留原payload并明确降级，失败不修改原包，不反写旧DB。
4. 核对历史AAR与本源码版本；当前只读分析没有构建/执行旧库，不能宣称等价。再冻结导入ID映射、alpha默认与坐标/pressure策略。

## 当前国内容器边界诊断（2026-10-27）

历史15文件字段快照继续固定原来源，不重哈希成当前源码等价。本轮单独固定当前jnotesv2的5个容器声明hash，见[container-framing.json](../fixtures/legacy/container-framing.json)。未找到现有.Jnotes真实样本，sample_archive_available=false；不能称为真实旧笔记迁移通过，也不能把NCPREVIEW v1 reader解释为JNotes导入器。

源码的外层zip.Jzip内层为DataOutputStream序列：writeUTF("TRY")、writeInt(version)、writeUTF(noteId)；每条writeInt(1)，然后type/location/name三个writeUTF、writeLong(len)、parentId/parentFilePath/des三个writeUTF及恰好len字节；writeInt(0)结束，尾部writeInt(version)、writeUTF("Lucky")、writeLong(19)。当前VERSION=2，版本1/2记录内容策略不同，容器诊断仅识别结构，绝不反序列化JSON/base64/proto或执行Java对象。

[诊断器](../tools/inspect_legacy_container.py)只读取单个zip.Jzip布局，不extract路径；Java writeUTF为modified UTF-8，NUL与补充字符均不能直接套普通UTF-8。只接受规范writeUTF编码（比Java readUTF宽松历史输入范围更窄），未知版本拒绝；未知type/location保留每条边界/长度/hash并明确migration_supported=false，不跳过后宣称成功。源name/父路径/正文不记录或当宿主文件路径使用。16MiB/10000记录只约束诊断，不是产品上限或完整旧格式支持。

[Java夹具](../fixtures/legacy/LegacyContainerFixture.java)真实DataOutputStream生成固定字节，包括中文/补充字符/NUL、未知记录及不可信父路径。首次使用Windows默认Java源码编码使非ASCII夹具不符预期，改为显式UTF8重生成后通过：

```text
java "-Dfile.encoding=UTF-8" fixtures/legacy/LegacyContainerFixture.java build/legacy-container-oracle.bin
python tools/verify_legacy_container.py
python tools/inspect_legacy_container.py <原包.Jnotes>
```

原包入口无写入或提取动作；8种framing异常和非单一zip.Jzip布局拒绝，synthetic ZIP前后字节保持。报告见[legacy-container-framing.json](../reports/legacy-container-framing.json)，catalog复用固定Java字节，不依赖旧工程或每次重新生成。采用明确容器/版本识别、严格边界和未知记录保留作为后续迁移前置规则；真实包、历史加密/不同容器布局、资源绑定/未知事件时间/笔种等payload转换与跨端往返仍未实现，原P1范围和门禁不变。
